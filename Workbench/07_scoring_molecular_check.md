# Custom molecular transparency check — 7 items

**Status (2026-09-20):** tool unchanged and not yet applied. Use alongside the appropriate JBI
tool only for finally eligible molecular studies after full-text retrieval.

Why: JBI tools do not cover sequencing/phylogeny quality. Apply alongside JBI for every molecular paper.
Score `Yes / No / Unclear` + quote. A `No` on 4 or 5 caps molecular claims at "suggestive".

1. **Sampling strategy stated?** Random/targeted/outbreak-driven; tissue/host/season; n per group.
2. **Assay transparency?** Primers, gene segments, Ct cutoffs, lab protocol or citation; HPAI pathotyping method.
3. **Sequencing transparency?** Platform, coverage/depth, segments sequenced (HA/NA vs full genome), QC.
4. **Accession available?** GenBank/GISAID IDs listed or "available on request" (latter = Partial at best).
5. **Phylogeny method + support?** Model, tree method (ML/Bayesian), bootstrap/posterior, outgroup, alignment length. "Phylogenetic analysis showed…" with no method = No.
6. **Clade nomenclature pinned?** System + version/date (e.g. H5 Gs/GD clade X, WHO/OIE/FAO naming); no silent switching between systems.
7. **Reassortment discipline?** ≥2 segments analysed + incongruence shown before claiming reassortment; distinguishes reassortment vs new introduction vs lineage replacement vs subtype change.

Language rule: subtype = HA/NA combo; clade/sublineage = within-subtype phylogeny; reassortant = segment incongruence demonstrated; introduction = phylogeographic link shown. Never interchange.
