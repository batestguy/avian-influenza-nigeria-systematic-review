# Screening forms — use for pilot + full run

## Title/abstract (answer Include / Exclude / Unsure per record)

1. Nigeria-linked? (conducted in Nigeria OR Nigeria-specific data extractable) — No → Exclude (non-Nigeria).
2. AIV in avian hosts with lab confirmation stated? — No → Exclude.
3. Any of: epi/prevalence/outbreak/surveillance, molecular/phylogenetic, spatial/temporal, wild-bird finding? — None → Exclude.
4. Primary/surveillance/outbreak/molecular-epi with extractable data? (editorial/news/abstract-without-data → Exclude).
5. If Unsure → tag for full-text, never guess-exclude on abstract alone.

Log: record ID, voter, vote, date. Conflicts resolved by discussion → arbiter. Pilot on same 30–50 records before full run.

## Full-text (one exclusion reason only — fixed list)

- non-Nigeria no Nigeria-data
- non-AIV
- no epi/molecular/spatial-temporal data
- no primary data
- experimental only no field relevance
- duplicate dataset (link primary: ____)
- unretrievable (after 2 attempts + author contact: date ____)

Include only if ALL include criteria (file 10) pass. Fill T6 row per excluded record.
