# PRISMA 2020 scoring — 27 items + 12-item abstract

**Status (2026-09-20):** audit template unchanged and not yet applied to a final report. Search
execution is documented, but Gate C screening reconciliation and all downstream stages remain
open; score the manuscript only after the reporting layer is updated.

Source: Page et al., BMJ 2021;n71 + explanation & elaboration n160; prisma-statement.org.
Use: audit the final `.docx`. Score each `Yes / Partial / No` + location.

## Title / Abstract / Intro (1–4)

1. **Title** — identifies report as systematic review. Yes only if "systematic review" in title.
2. **Abstract** — see 12-item abstract block below. Score whole abstract separately.
3. **Rationale** — why review needed, what it adds vs Kalonda 2020 + Akanbi & Lakes 2025.
4. **Objectives** — explicit question(s) with CoCoPop elements (Condition, Context, Population).

## Methods (5–15)

5. **Eligibility** — inclusion + exclusion + grouping for syntheses defined upfront.
6. **Information sources** — every database/register/website/org/reference-list + date last searched.
7. **Search strategy** — FULL line-by-line strategy for EVERY source, filters/limits included.
8. **Selection process** — reviewers per stage, independence, conflict resolution, automation if any.
9. **Data collection** — extractors per report, independence, author-contact, automation if any.
10a. **Outcomes sought** — which results sought per outcome domain, how subsets chosen.
10b. **Other variables** — participants, virus/host/methods, funding; assumptions on missing info.
11. **RoB in studies** — tool(s), reviewers, independence, automation; study- or outcome-level.
12. **Effect measures** — for us: standardized metric per synthesis (first detection, occurrence, clade assignment) — state it even without meta-analysis.
13a. **Synthesis eligibility** — how studies mapped to each synthesis grouping.
13b. **Data preparation** — missing stats, conversions, handling of duplicates/overlaps.
13c. **Tabulation/display** — tables/plots used, ordering rules.
13d. **Synthesis method + rationale** — SWiM method named + why no meta-analysis.
13e. **Heterogeneity exploration** — subgroup/sensitivity logic (e.g. surveillance intensity vs true emergence).
13f. **Sensitivity analyses** — robustness checks (peer-only vs +grey).
14. **Reporting bias** — missing-results assessment method.
15. **Certainty** — GRADE-prognosis method, outcomes covered, reviewer count.

## Results (16–22)

16a. **Flow** — records at each stage, PRISMA flow diagram.
16b. **Excluded with reasons** — near-misses cited + reason each.
17. **Study characteristics** — each include cited + tabled.
18. **RoB per study** — present per study (table/traffic-light).
19. **Individual study results** — per study summary stats as applicable, structured tables.
20a. **Synthesis sample** — characteristics + RoB of contributing studies per synthesis.
20b. **Synthesis results** — all syntheses reported; direction described (no fake pooled estimate).
20c. **Heterogeneity results** — findings of explorations.
20d. **Sensitivity results** — findings of robustness checks.
21. **Reporting biases** — assessment per synthesis.
22. **Certainty of evidence** — rating per outcome/synthesis + reasons.

## Discussion / Other (23–27)

23a–d. **Interpretation, evidence limitations, method limitations, implications** — all four present and separated.
24a–c. **Registration + protocol + amendments** — register name + number OR explicit "not registered"; protocol location OR "no protocol"; amendments explained.
25. **Support** — funding + roles.
26. **Competing interests** — declared.
27. **Data/code/materials availability** — extraction forms, extracted data, code, other materials: location or statement. (For us: "in-manuscript tables".)

## Abstract 12-item block (score separately)

1 Title = systematic review. 2 Objectives. 3 Eligibility. 4 Sources + date. 5 RoB methods. 6 Synthesis methods. 7 Included studies (n) + key traits. 8 Synthesis results per main outcome (n + direction). 9 Limitations of evidence. 10 Interpretation. 11 Funding. 12 Registration number or "not registered".
