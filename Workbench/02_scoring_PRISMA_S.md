# PRISMA-S scoring — 16 items (search reproducibility)

**Status (2026-09-20):** active audit template. Exact AJOL and Web of Science browser strings,
dates, counts, and export limitations are now in files 15 and 19. Final scoring waits for record
import, canonical reconciliation, and a complete source-level PRISMA accounting table.

Source: Rethlefsen et al., Syst Rev 2021;10:39. Complements PRISMA 2020 Items 6–7.
Score each `Yes / Partial / No` + location. Q1 bar: zero `No` on 4–9.

1. **Database name + platform** — e.g. PubMed via NLM, Scopus via Elsevier. Vendor required.
2. **Grey / supplementary sources** — theses, WOAH reports, reference lists, citation chasing: named.
3. **Date(s) searched** — per source, full date.
4. **Limits / filters** — language, date, publication status, with justification.
5. **Records per source** — hits per database stated.
6. **Dedupe method** — tool + manual verification; auto vs manual counts.
7. **Update search** — rerun before analysis/submission, date stated (or why not).
8. **Full strategy per source** — copy-pasted AS RUN, with fields/tags/MeSH/Boolean/truncation.
9. **Peer review of strategy** — PRESS or second-person check (or state none).
10. **Study selection flow from search** — records into screening accounted for.
11. **Search ethics / translation** — non-English handling, author contact.
12. **Google Scholar rule** — ranked sort + cap (e.g. first 200 by relevance) recorded; never "searched Google Scholar" alone.
13. **AJOL handling** — free-text variants recorded (AJOL has weak controlled vocab).
14. **Citation chasing log** — backward/forward citations tracked per include.
15. **Search files retained** — export files / screenshots location stated (workbench log, not manuscript).
16. **Amendments** — any post-freeze string changes dated + justified.
