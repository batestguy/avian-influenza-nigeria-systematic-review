# Formats we will use when drafting ours

All tables/appendices live INSIDE the `.docx` at draft stage (user rule). British English throughout.

## Table shells (column order frozen)

**T1 First-detection chronology:** Year | Subtype | Clade/lineage | State + host/system | Detection method | n | Accession | Ref. One row per event; order by year.
**T2 State × epoch matrix:** rows = states/zones, columns = 2006–10 / 11–14 / 15–20 / 21–26, cells = subtype(s) + host code + ref. Empty = `NR` (not reported), never blank.
**T3 Host-range:** Host/system (commercial / backyard / LBM / wild-migratory / wild-resident) | Subtypes detected | Clades | Period | Ref.
**T4 Clade transitions:** Period | Outgoing clade | Incoming clade | Evidence (segments, support, accessions) | Introduction vs local evolution verdict | Ref.
**T5 Accession + methods audit:** Study | Segments | Platform | Phylogeny method/model/support | Accession Yes/Partial/No | Molecular check notes.
**T6 Excluded at full-text:** Study | Year | Reason (one reason only, from fixed list).
**T7 RoB summary:** Study | Design | JBI overall | Key domain concerns | Molecular check flags.

Fixed exclusion reasons: non-Nigeria no Nigeria-data | non-AIV | no epi/molecular/spatial-temporal data | no primary data | experimental only no field relevance | duplicate dataset.

## Figure specs (draft as placeholders, separate files only at submission)

F1 PRISMA 2020 flow (counts at every arrow). F2 Timeline of first detections. F3 Nigeria state map shading by epoch. F4 Clade-transition schematic. Captions state n + contributing studies.

## Style rules

- Times New Roman, numeric brackets `[1]`, numbered order, DOI per ref. No BibTeX/Zotero.
- Cells: `Not reported / Unclear / N/A` — never blank. Dates `DD Mon YYYY`. States use official names.
- Abstract last, to PRISMA-for-Abstracts 12 items. Discussion splits evidence limitations vs method limitations.
